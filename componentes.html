POSTGRESQL // SUPABASE
CRUD HYDRA_CRUD — PUERTO 8080
CRUD clínico principal: pacientes, fichas, citas, recetas, exámenes, documentos y fotografías. Valida reglas de negocio y expone los recursos clínicos al resto de las interfaces.
SEC HYDRA_ARM_SECURITY — PUERTO 8081
Autenticación y autorización. Emite JWT firmados con RSA256, aplica RBAC, cifra el RUT y los mensajes, y administra los archivos adjuntos con acceso controlado.
GEO GEOLOCALIZACION — PUERTO 8082
Registra y consulta la ubicación del paciente, habilita el seguimiento en mapas y entrega datos para alertas de zona y emergencias.
RT HYDRA_REALTIME — PUERTO 8083
Puente de eventos en tiempo real mediante SSE. Distribuye BPM, SpO2, batería y alertas clínicas a la APK, la aplicación de escritorio y la web.
CLIENTES DEL ECOSISTEMA
Tres interfaces comparten el mismo backend y el mismo modelo de datos, adaptadas a cada contexto de uso.
APK APLICACION MOVIL
Angular 20 + Ionic 8 + Capacitor 8 + TypeScript. Vista del paciente y del familiar: monitoreo, alertas, selección de pacientes y perfil clínico.
EXE APLICACION DE ESCRITORIO
Electron + HTML/CSS/JavaScript + Leaflet. Paneles de médico, cuidador, administrador y autorizador; gestión clínica, recetas, documentos, chat y mapas.
WEB APLICACION WEB
Astro + TypeScript. Interfaz administrativa para empleados de farmacia: login y visualización/confirmación de recetas en PDF.
CAPA DE DATOS
PostgreSQL en Supabase como persistencia compartida. Supabase Storage (S3) para documentos, fotografías y adjuntos. PostgREST para consultas administrativas controladas.

Entidades principales: usuarios y roles, pacientes y fichas clínicas, citas, recetas, exámenes, documentos, mensajes, alertas, ubicaciones y solicitudes de prótesis.
usuarios(id, rut_cifrado, rut_hash, nombre, rol_id, ...) pacientes(id, usuario_id, cobertura, ficha_clinica, ...) dispositivos(id, paciente_id, esp32_mac, ultima_conexion, ...) telemetria(id, dispositivo_id, bpm, spo2, bateria, lat, lng, timestamp) alertas(id, paciente_id, tipo, severidad, estado, timestamp)
HARDWARE IoT
El ESP32 conecta la prótesis robótica con la plataforma mediante WiFi y Bluetooth Low Energy. Transmite frecuencia cardíaca (BPM), saturación de oxígeno (SpO2), nivel de batería y geolocalización.

Los umbrales de taquicardia, bradicardia y SpO2 baja generan alertas automáticas a médico y cuidador.
