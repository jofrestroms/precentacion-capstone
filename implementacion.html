STACK Y REPOSITORIOS
Hydra se implementa con un stack unificado para reducir la curva de aprendizaje y reutilizar componentes. Cada microservicio y cada cliente mantiene control de versiones independiente en GitHub.
JAVA HYDRA_CRUD
Spring Boot · puerto 8080 · CRUD clínico principal.
JAVA HYDRA_ARM_SECURITY
Spring Boot · puerto 8081 · autenticación, cifrado y archivos.
JAVA GEOLOCALIZACION
Spring Boot · puerto 8082 · ubicación del paciente.
JAVA HYDRA_REALTIME
Spring Boot · puerto 8083 · puente de eventos SSE.
APK HYDRA_ARM_APK_V2
Angular 20 + Ionic 8 + Capacitor 8. Empaquetado Android.
EXE APP-ESCRITORIO-HYDRA
Electron. Paneles de médico, cuidador, administrador y autorizador.
WEB HYDRA_WEB
Astro + TypeScript. Interfaz administrativa de farmacia.

CONFIGURACION Y DESPLIEGUE
La configuración se inyecta por variables de entorno en Render y Supabase. Ningún secreto se versiona en los repositorios.
server: port: ${PORT:8080} spring: application: name: hydra_crud datasource: url: ${SUPABASE_DB_URL} username: ${SUPABASE_DB_USER} password: ${SUPABASE_DB_PASSWORD} jpa: hibernate: ddl-auto: validate properties: hibernate: format_sql: true
Render: despliegue independiente por microservicio, con health checks y variables de entorno. Cloudflare: publicación del frontend y protección perimetral. Supabase: PostgreSQL administrado y almacenamiento de archivos.
SEGURIDAD IMPLEMENTADA
JWT con firma RSA256 e integridad HMAC. Cifrado en reposo del RUT y de los mensajes. Hash SHA-256 para búsquedas sin exponer el dato. RBAC por rol. CORS restringido, rate limiting y WAF. HTTPS/TLS en todas las comunicaciones y auditoría de accesos.
@Bean SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception { http .csrf(csrf -> csrf.disable()) .cors(Customizer.withDefaults()) .authorizeHttpRequests(auth -> auth .requestMatchers("/api/auth/**").permitAll() .requestMatchers("/api/pacientes/**").hasAnyRole("MEDICO","ADMIN") .anyRequest().authenticated()) .sessionManagement(s -> s.sessionCreationPolicy(STATELESS)) .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class); return http.build(); }
TIEMPO REAL E IoT
El ESP32 envía las lecturas a la API; Hydra Realtime las distribuye por SSE a las tres interfaces. Las alertas se generan cuando BPM o SpO2 salen de los rangos fisiológicos definidos.
@GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE) public SseEmitter stream() { SseEmitter emitter = new SseEmitter(0L); emitter.onCompletion(() -> registry.remove(emitter)); emitter.onTimeout(() -> registry.remove(emitter)); registry.add(emitter); return emitter; }
